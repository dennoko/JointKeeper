# JointKeeper ユーザーマニュアル

対象バージョン: v0.1.0  
動作環境: Unity 2022.3 / VRChat SDK 3.7.0 以降 / NDMF

---

## 1. 概要

JointKeeper は、VRChat アバターの肘・膝を曲げたときの潰れや素体の貫通、および前腕をひねったときの袖のねじれ潰れを軽減する NDMF 対応ツールです。

- **肘・膝のボリューム維持**
  肘や膝を曲げたときに外側がへこんで素体が貫通する現象を抑えます。ビルド時に VRC Parent Constraint を使った補助ボーンを生成し、関節周辺のウェイトを再配分します。
- **前腕ツイスト分散**
  手首をひねったときに肘付近で袖が急激にねじれて細くなる現象を抑えます。VRC Aim Constraint と VRC Rotation Constraint を使った補助ボーンを追加し、ねじれを肘から手首にかけて分散します。既定ではオフです。
- **非破壊ビルドとベイク出力**
  通常は NDMF により元のアセットを変更せずビルド時に適用されます。他ツールとの競合を避けたい場合向けに、シーンへ直接書き出して差し替えるベイク機能もあります。

---

## 2. クイックスタート

1. Hierarchy で衣装のルートオブジェクト、衣装メッシュ、またはアバタールートを選択します。
2. 右クリックメニューから `dennokoworks` → `JointKeeper` を選択します。
   - Inspector の `Add Component` → `dennokoworks` → `Joint Keeper` からも追加できます。
   - 追加直後は Inspector が折りたたまれた状態になります。
3. そのまま Play モードやアップロードを実行すると、NDMF ビルド時に肘・膝の補正が適用されます。

### Edit モードでの確認

1. `JointKeeper` コンポーネントを展開します。
2. `Edit モード曲げプレビュー` をオンにします。
3. `曲げ角` スライダーを動かして Scene ビューで曲がり方を確認します。シーン上のボーンやメッシュは変更されません。
4. 素体がわずかに貫通する場合は `90° 押し出し量` を `0.003`〜`0.006` m 程度に上げます。

## 3. 機能紹介

### 3.1 肘・膝の基本設定

| 項目 | 既定値 | 内容 |
| --- | --- | --- |
| 左 / 右 | オン | 左右それぞれの補正を有効または無効にします。 |
| 強度 | `0.85` | 補助ボーンへ移すウェイトの強さです。`0` で効果なし、`1` で最大になります。 |
| 90° 押し出し量 | `0.002` m | 90° 曲げたときに関節の外側へ押し出す距離です。貫通が残る場合に増やします。 |

### 3.2 前腕ツイスト分散

肘専用の機能です。既定ではオフになっています。肘の補助ボーンと併用できます。

| 項目 | 既定値 | 内容 |
| --- | --- | --- |
| 有効化トグル | オフ | 前腕ツイスト分散のオン・オフを切り替えます。 |
| ひねり追従率 | `1.0` | 手首側で腕のひねりに追従する割合です。肘側は常に `0` になります。`1.0` では手首の動きを変えず肘のねじれだけを分散します。値を下げると袖全体のひねりが抑えられます。 |

長袖・七分袖・アームカバーなど、手首より先にウェイトがない衣装での使用を想定しています。手袋や手の甲まで覆う袖、素体メッシュでは、手首に段差が出ないよう `ひねり追従率` を `1.0` のまま使用してください。

### 3.3 Edit モード曲げプレビュー

- **曲げ角**: `0°`〜`150°` の範囲で肘と膝の曲げ具合を確認します。
- **前腕ツイスト**: `-90°`〜`+90°` の範囲で前腕のひねりを確認します。
- **適用前と比較**: 同じ曲げ角のまま補正前の状態を表示し、変化を比較します。
- **ヒートマップ表示**:
  - `Off`: 通常表示に戻します。
  - `HelperWeight`: 補助ボーンのウェイト分布を色分け表示します。
  - `FourBoneDiagnostics`: 1 頂点あたり 4 ボーン制限に対する調整状態を色分け表示します。
- **リセット**: 曲げ角・前腕ツイスト・適用前比較を初期状態へ戻します。

### 3.4 Scene ビューの表示

コンポーネントを選択すると、各関節に以下のガイドが表示されます。

- **シアンの楕円球**: 補正の影響範囲
- **緑色の円**: 外側に向かって効果が弱まり始める境界
- **オレンジの矢印**: 関節の外側の向き
- **赤色の線**: 関節の曲げ軸

### 3.5 破壊的ベイク

現在の設定で補助ボーンとメッシュ `.asset` を直接生成して差し替える機能です。メッシュ `.asset` は元メッシュと同じフォルダに保存されます。

- **ベイクして差し替え**: 補助ボーンとメッシュを生成して差し替え、コンポーネントを自動無効化します。NDMF ビルド時の二重適用は起きません。
- **再ベイク**: 前回のベイクを元に戻してから、現在の設定でベイクし直します。
- **元に戻す**: 元のメッシュとボーン構成に戻し、生成した補助ボーンと `.asset` を削除します。
- **コンポーネントを削除して確定**: ベイク結果を残したまま `JointKeeper` コンポーネントを削除します。実行後は「元に戻す」は使えません。
- **生成済みアセット・補助ボーン一覧**: 生成されたファイルとボーンを確認できます。

前腕ツイスト分散は破壊的ベイクに未対応です。NDMF ビルド時のみ適用されます。

### 3.6 表示言語とバージョン確認

Inspector 上部のヘッダーから、日本語・英語の切り替えとバージョン確認ができます。`↻` ボタンで最新バージョンを再確認できます。

## 4. 詳細機能紹介

Inspector の `詳細設定` を開くと以下の項目を調整できます。

### 4.1 対象メッシュ設定

- **検出モード**:
  - `AutoDetect`: コンポーネント配下の `SkinnedMeshRenderer` を自動で対象にします。
  - `ManualList`: `対象メッシュ` に登録したメッシュのみを対象にします。
- **除外メッシュ**: `AutoDetect` 時に処理対象から外したいメッシュを指定します。アバタールートに配置して素体を除外したい場合などに使います。

### 4.2 左右個別に調整

既定ではオフで、左側の設定が右側へ左右反転して適用されます。左右非対称な衣装を個別に調整する場合にオンにします。

### 4.3 関節リグ・影響範囲の詳細設定

| 項目 | 既定値 | 内容 |
| --- | --- | --- |
| 追従率 | `0.50` | 補助ボーンが前腕や下腿の回転に追従する割合です。`0.50` で上側と下側の中間角度になります。 |
| 分配カーブ指数 | `1.2` | 関節中心から離れた頂点への減衰の強さです。大きいほど折り目付近に集中します。 |
| ピボット調整 | `0, 0, 0` m | 補助ボーンと影響範囲の中心位置を微調整します。 |
| 外側方向オフセット | `0°` | オレンジ矢印の向きを腕・脚の軸回りに回転調整します。 |
| 軸方向影響半径 | `0.35` | 腕・脚の長さ方向に対する影響範囲の比率です。 |
| 径方向影響半径 | `0.45` | 腕・脚の太さ方向に対する影響範囲の比率です。ゆったりした袖やワイドパンツでは大きめにします。 |
| 減衰開始比 | `0.25` | 端に向かって効果が弱まり始める位置です。緑色の円に対応します。 |
| 内側カットオフ | `-0.15` | 関節の内側で補正を最小まで絞る位置の目安です。値を上げるほど外側寄りに限定されます。 |
| 外側フル開始 | `0.35` | 関節の外側で補正が最大になる位置の目安です。 |
| 内側最小維持率 | `0.0` | 関節の内側に残す最小の補正割合です。通常は `0` のままにします。 |
| 境界判定閾値 | `0.01` | 上側と下側の両方にこの値以上のウェイトを持つ頂点だけを補正対象にします。 |

- **Scene ビュー操作ハンドルを表示**: Scene ビュー上でピボット位置や外側方向をドラッグして調整できます。
- **関節フレーム再計算**: アバターの Humanoid 設定から実際の曲げ軸と前腕の回転軸を再計測します。

### 4.4 前腕ツイスト分散の詳細設定

| 項目 | 既定値 | 内容 |
| --- | --- | --- |
| 区間数 | `3` | 前腕のねじれを分割する数です。`1`〜`4` を指定できます。`2` にすると Constraint 数を減らせます。 |
| 分配開始位置 / 終了位置 | `0.0` / `1.0` | ねじれを分散する範囲を前腕の長さに対する比率で指定します。`0` が肘、`1` が手首です。 |
| 分配カーブ / カーブ指数 | `Linear` / `1.0` | ねじれの配分方法です。`Linear` は均等、`Power` は指数に応じて手首寄り、`SmoothStep` は両端が緩やかになります。 |
| 肘補助ボーンを曲げのみ追従にする | オン | 肘の補助ボーンが前腕のひねりを拾わないようにします。 |
| 既存ツイストリグがあっても適用 | オフ | 既存の前腕ツイストボーンにウェイトがあるメッシュにも強制適用します。既存ボーンのウェイトは変更しません。 |
| ノット丸め閾値 | `0.15` | 分割点の端に近い頂点を単一ボーンにまとめてウェイト数を節約する閾値です。 |

### 4.5 ツイストボーン分類・4ボーン制限・診断

- **ツイストボーン自動分類**: 既存のツイストボーンや補助ボーンを、階層と Constraint の関係から上側・下側へ自動分類します。
- **遠位ソースモード / 上書き**: 補助ボーンが参照する下側ボーンの選び方を変更します。通常は既定のままで問題ありません。
- **手動追加・手動除外ボーン**: 自動分類で拾えないボーンの追加や、揺れものボーンの除外を指定します。
- **4ボーン Tier2 吸収閾値 / Tier3 ノイズ閾値**: 1 頂点あたり 4 ボーンの上限に達したとき、微小なウェイトを整理して補助ボーン用の枠を確保する閾値です。
- **ツイストボーン検出・診断**: 対象メッシュの各ボーンの分類結果や、前腕の回転軸の計測状態を確認できます。

## 5. 対象とするモデルの注意点

1. **Humanoid 設定が必要**
   親階層に Humanoid の Animator が必要です。前腕ツイスト分散を使う場合は、`Hand` ボーンが割り当てられており、Humanoid の前腕ひねり動作で `LowerArm` が回転するアバターである必要があります。
2. **関節周辺のウェイト分布**
   肘・膝の補正は、影響範囲内で上側ボーンと下側ボーンの両方に `0.01` 以上のウェイトを持つ頂点が対象です。関節の境目でウェイトが完全に分かれている硬質パーツや、肘・膝に頂点がないメッシュは自動でスキップされます。
3. **既存ツイストボーンとの併用**
   Constraint で動く既存のツイストボーンは自動で認識されます。前腕ツイスト分散は、すでに既存の前腕ツイストボーンにウェイトが乗っているメッシュでは二重適用を避けるため自動でスキップされます。
4. **手首より先にウェイトがあるメッシュ**
   手袋や手の甲まで覆う袖、素体メッシュで前腕ツイスト分散を使う場合、`ひねり追従率` を `1.0` 未満にすると手首で段差が生じます。`1.0` のまま使用してください。
5. **前腕の PhysBone**
   袖口のリボンなど前腕に PhysBone が付いている部位は元のボーンの回転で動き続けるため、前腕ツイスト分散をオンにすると周囲の袖とずれる場合があります。
6. **Modular Avatar との併用**
   `MA Merge Armature` や `MA Scale Adjuster`、Blender 出力の 100 倍スケール Armature に対応しています。破壊的ベイクを実行した後に `MA Scale Adjuster` の値を変更した場合は、`再ベイク` を実行してください。

## 6. Q&A

### Q. ボーンや Constraint は何本追加されますか？ 増える条件はありますか？

**肘・膝のボリューム維持**
- 有効な関節ごとに、補助ボーン 1 本と VRC Parent Constraint 1 個が追加されます。
- 同じ関節でリグ設定が一致する複数メッシュ・複数衣装では、同じ補助ボーンが共有されます。標準設定のまま複数の衣装に付けても、追加は最大 4 ボーン・4 Constraint です。
- 同じ関節に対して異なる押し出し量・追従率・ピボット位置・外側方向オフセットなどを設定したコンポーネントがある場合のみ、設定ごとに 1 本ずつ追加されます。
- 対象メッシュに関節境界の頂点がない関節ではボーンは追加されません。

**前腕ツイスト分散**
- 有効な肘 1 箇所につき、Aim ターゲット 1 本、曲げ専用基準ボーン 1 本、中間ツイストボーンが追加されます。
- 中間ツイストボーンは `区間数 - 1` 本です。`ひねり追従率` が `1.0` 未満のときは `区間数` 本になります。
- 既定値では片腕あたり 4 ボーン・3 VRC Constraint、両腕で 8 ボーン・6 VRC Constraint です。同じ腕の複数メッシュ間で共通設定のボーンは共有されます。

### Q. パフォーマンスランクへの影響はありますか？

追加される Constraint はすべて VRC Constraint です。標準設定の肘・膝のみであれば最大 4 ボーン・4 Constraint の増加にとどまります。前腕ツイスト分散で Constraint 数を抑えたい場合は、`区間数` を `2` にすると両腕で 6 ボーン・4 Constraint まで減らせます。

### Q. 複数の衣装とアバタールートに同時に付けても問題ありませんか？

問題ありません。同じメッシュ・同じ関節に複数のコンポーネントが重なった場合は、以下の優先順位で 1 つだけが適用されます。

1. `ManualList` 指定が `AutoDetect` より優先されます。
2. メッシュに近いオブジェクトのコンポーネントが親側のコンポーネントより優先されます。

### Q. Modular Avatar や Avatar Optimizer と併用できますか？

併用できます。NDMF の `Transforming` フェーズで Modular Avatar の後、Avatar Optimizer の前に実行されます。

### Q. Edit モード曲げプレビューで元のアバターは変更されますか？

変更されません。NDMF Preview の一時データ上で表示しているため、シーン上のボーンや元のメッシュは書き換わりません。

### Q. 付けたのに効果が出ない・ボーンが生成されない場合は？

以下を確認してください。

1. Humanoid の Animator を持つアバター配下にコンポーネントが置かれているか。
2. 肘・膝付近に上側・下側の両方のウェイトが乗った頂点があるか。`ヒートマップ表示` の `HelperWeight` で確認できます。
3. 破壊的ベイク済み状態になっていないか。ベイク済みの間は NDMF ビルドがスキップされるため、設定変更後は `再ベイク` を実行してください。
4. `ツイストボーン検出・診断` および Unity の Console にメッセージが出ていないか。
