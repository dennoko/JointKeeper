# JointKeeper ユーザーマニュアル

**対象バージョン:** v0.1.0  
**動作環境:** Unity 2022.3 / VRChat SDK 3.7.0 以降（VRC Constraints 対応）/ NDMF（非破壊ビルド・プレビュー用）

---

## 1. 概要（何を解決するか）

**JointKeeper** は、VRChat アバターの **肘・膝の曲げ潰れ** や **前腕のねじれ潰れ** を、コンポーネントを付けるだけで非破壊（NDMF）に軽減する Unity エディタ拡張です。

- **肘・膝のボリューム維持（貫通防止）**
  通常のスキニング（Linear Blend Skinning）では、肘や膝を深く曲げると関節の外側（肘頭・膝頭側）が内側にへこみ、袖やズボンから素体が貫通したり、関節が不自然に細くなったりします。JointKeeper はビルド時に **VRC Parent Constraint 駆動の補助ボーン** を自動生成し、関節境界のウェイトを自動再配分することでボリュームを保ちます。
- **前腕ツイスト分散（オプション・肘専用）**
  手首をひねった際に肘付近で袖が急激にねじれ細る（キャンディラッパー現象）のを防ぐため、曲げ専用の基準ボーンと中間ツイストボーン（VRC Aim / Rotation Constraint 駆動）を追加し、肘から手首にかけてねじれをなめらかに分散します。
- **非破壊ワークフロー ＆ 破壊的ベイク両対応**
  通常は NDMF により元のアセットを一切変更せずビルド時に適用されます。他ツールとの競合回避が必要な場合は、いつでも元に戻せる「破壊的ベイク（Bake & Replace）」も利用できます。

---

## 2. クイックスタート（最低限の使い方）

基本的には **対象オブジェクトにコンポーネントを付けるだけ** で動作します。

1. Hierarchy で **衣装のルートオブジェクト**（または衣装メッシュ、`Armature` を含むアバタールート）を選択します。
2. 右クリックメニューから **`dennokoworks` → `JointKeeper`** を選択します。
   - Inspector の `Add Component` → **`dennokoworks` → `Joint Keeper`** からも追加できます。
   - 付けるだけで使える設計のため、追加直後は Inspector が折りたたまれた状態になります。
3. そのまま **Play モード（Gesture Manager 等）で確認**、または **VRChat へアップロード** すると、NDMF ビルド時に自動で肘・膝の補正が適用されます。

### Edit モードで動きを確認したい場合

1. `JointKeeper` コンポーネントを展開します。
2. **`Edit モード曲げプレビュー (NDMF Preview)`** を ON にします。
3. **`曲げ角 (Bend °)`** スライダーを動かすと、シーン上のボーンを一切回転させずに肘・膝の曲がり具合をリアルタイムで確認できます。
4. わずかに素体が貫通する場合は **`90° 押し出し量 (m)`** を `0.003`〜`0.006` 程度に上げてください。

## 3. 機能紹介

### 3.1 肘 (Elbows) / 膝 (Knees) の基本設定

| 項目 | 既定値 | 説明 |
| --- | --- | --- |
| **左 (Left) / 右 (Right)** | ON | 左右それぞれの補正を有効／無効にします。 |
| **強度 (Strength)** | `0.85` | 補助ボーンへ移すウェイトの強さ（`0` = 効果なし、`1` = 最大維持）。通常は `0.85` 前後が自然です。 |
| **90° 押し出し量 (m)** | `0.002` | 90° 曲げた際に肘頭・膝頭方向へ押し出す距離（m）。素体貫通が残る場合は少し増やします。 |

### 3.2 前腕ツイスト分散 (Forearm Twist)（肘専用・既定 OFF）

腕をひねったときに肘で袖が急にねじれるのを防ぎ、肘から手首へなめらかにねじれを分散します。肘の補助ボーンと併用できます。

| 項目 | 既定値 | 説明 |
| --- | --- | --- |
| **有効化トグル** | OFF | 前腕ツイスト分散を有効にします。 |
| **ひねり追従率** | `1.0` | 手首側でのひねり追従率（肘側は常に `0` = 曲げのみ追従）。`1.0` なら手首の動きを変えずに肘のねじれだけを分散します。`0` に近づけるほど袖全体のひねりが抑えられます。 |

> **推奨対象:** 長袖・七分袖・アームカバーなど、手首から先（`Hand` 以降）にウェイトが乗っていない衣装。  
> 手袋・手の甲まで覆う袖・素体メッシュでは、手首で段差が出ないよう **ひねり追従率を `1.0` のまま** お使いください。

### 3.3 Edit モード曲げプレビュー (NDMF Preview)

シーン上の元ボーンや元メッシュを変更せず、Scene ビュー上で結果を確認できます。

- **曲げ角 (Bend °)** (`0°`〜`150°`): 肘と膝の曲げ角度を調整します。
- **前腕ツイスト (Twist °)** (`-90°`〜`+90°`): 前腕のひねり角度を調整し、ツイストボーンや前腕ツイスト分散の追従を確認します。
- **適用前と比較 (Before 表示)**: 同じ曲げ角のまま JointKeeper 適用前の状態を表示し、ON/OFF で効果を A/B 比較できます。
- **ヒートマップ表示**:
  - `Off`: 通常マテリアル表示。
  - `HelperWeight`: 補助ボーンへ配分されたウェイトの強さを色分け表示。
  - `FourBoneDiagnostics`: VRChat の 1 頂点あたり最大 4 ボーン制限に対する統合処理（Tier 1〜3）の状態を色分け表示。
- **リセット**: 曲げ角・ツイスト角・Before 比較を初期状態（`0°`）へ戻します。

### 3.4 Scene ビューのギズモ表示

コンポーネントを選択すると、各関節に以下のギズモが表示されます。

- **シアンの楕円球**: 補正の影響範囲（ROI）。
- **緑色の円**: 中心から外側に向かって効果が減衰し始める境界（`減衰開始比` に対応）。
- **オレンジの矢印**: 関節の外側方向（肘頭・膝頭が張り出す向き）。
- **赤色の線**: 関節の曲げ軸（ヒンジ軸）。

### 3.5 破壊的ベイク (Bake & Replace)

他ツールとの競合回避や事前適用を行いたい場合に、現在の設定でメッシュ `.asset` と補助ボーンをシーン・プロジェクトへ直接生成して差し替えます。

- **ベイクして差し替え (Bake & Replace)**: 元メッシュと同じフォルダに `.asset` を保存して差し替え、コンポーネントを自動無効化します（NDMF ビルド時の二重適用を自動防止）。
- **再ベイク (Re-Bake)**: スライダー調整後に一度元へ戻してから新しくベイクし直します。
- **元に戻す (Revert)**: 元のメッシュ・ボーン配列を復元し、生成した補助ボーンと `.asset` を削除して非破壊モードへ戻します。
- **コンポーネントを削除して確定 (Revert 不可)**: ベイク済みメッシュと補助ボーンを残したまま `JointKeeperComponent` のみ削除します。
- **生成済みアセット・補助ボーン一覧**: 生成されたアセット・ボーンを一覧表示し、クリックで Project / Hierarchy 上にハイライトできます。

> ※ **前腕ツイスト分散** は現在 `Bake & Replace` に未対応です（NDMF ビルド時のみ適用されます）。

### 3.6 多言語対応 ＆ バージョン確認

Inspector 上部のヘッダーから以下を利用できます。

- **言語切替ボタン（`JA` / `EN`）**: Inspector の表示言語・ツールチップを日本語／英語で即時切り替えできます。
- **アップデート確認**: 現在のバージョン表示と最新版の確認（`↻` ボタンで再確認、更新がある場合はリリースページへのリンクを表示）。

## 4. 詳細機能紹介

Inspector の **`詳細設定 (Advanced)`** を開くと、以下の詳細パラメータを調整できます。

### 4.1 対象メッシュ設定

- **検出モード (`AutoDetect` / `ManualList`)**
  - `AutoDetect`: コンポーネントを付けたオブジェクト配下の `SkinnedMeshRenderer` を自動検出します。
  - `ManualList`: **`対象メッシュ (Manual)`** リストに指定したメッシュのみを処理します。
- **除外メッシュ (Excluded)**: `AutoDetect` 時に処理から外したいメッシュを指定します（アバタールートに配置して素体だけ除外したい場合など）。

### 4.2 左右個別に調整 (Unlink L/R)

既定では OFF になっており、左側の設定が右側へ自動でミラー適用されます（`ピボット調整` の `Z` と `外側方向オフセット` は符号反転）。左右非対称な衣装を個別に詰めたい場合のみ ON にしてください。

### 4.3 関節リグ・影響範囲（ROI）の詳細パラメータ

| 項目 | 既定値 | 説明 |
| --- | --- | --- |
| **追従率 (Bend Follow Ratio)** | `0.50` | 補助ボーンが下肢の回転に追従する割合（`0.5` で上肢と下肢の中間角度）。 |
| **分配カーブ指数 (Gamma)** | `1.2` | 関節中心から離れた頂点への減衰の鋭さ。高いほど折り目付近に集中します。 |
| **ピボット調整 (Axial, Out, Hinge)** | `(0, 0, 0)` | 補助ボーンと影響範囲の中心位置をメートル単位で微調整します（X: 肢軸 / Y: 外側 / Z: ヒンジ軸）。 |
| **外側方向オフセット (deg)** | `0°` | オレンジ矢印（外側方向）を肢軸回りに回転調整します。 |
| **軸方向影響半径 (肢長比)** | `0.35` | 腕・脚の長さ方向の影響半径（シアン楕円の上下幅）。 |
| **径方向影響半径 (肢長比)** | `0.45` | 腕・脚の太さ方向の影響半径。ゆったりした袖やワイドパンツでは大きめにします。 |
| **減衰開始比** | `0.25` | 端に向かって効果が弱まり始める境界位置（緑の円に対応）。 |
| **内側カットオフ** | `-0.15` | 関節の内側（肘の内側・膝裏）で補正を最小まで絞る内積閾値。 |
| **外側フル開始** | `0.35` | 関節の外側で補正が 100% フルに効き始める内積閾値。 |
| **内側最小維持率** | `0.0` | 関節の内側に残す最小の補正割合。通常は `0` にして自然な折り込みを保ちます。 |
| **境界判定閾値** | `0.01` | 近位（上肢側）・遠位（下肢側）の両方にこの値以上のウェイトを持つ頂点のみを境界として扱います。 |

- **Scene ビュー操作ハンドルを表示 (Pivot / Outward)**: ON にすると Scene ビュー上でピボット位置や外側方向を直接ドラッグ調整できます。
- **関節フレーム再計算（マッスル軸実測）**: 一時クローン上で Humanoid マッスルをわずかに動かし、実際の肘・膝のヒンジ軸と前腕ロール軸を再実測します。

### 4.4 前腕ツイスト分散の詳細パラメータ

| 項目 | 既定値 | 説明 |
| --- | --- | --- |
| **区間数** | `3` | 前腕を何区間に分けてねじれを分散するか（`1`〜`4`）。`3` で 90° ひねり時の細りは約 3.4%、`2` で約 7.6%。Constraint 数を抑えたい場合は `2` にします。 |
| **分配開始位置 / 終了位置** | `0.0` / `1.0` | ねじれ分配の開始・終了位置（前腕長比、`0` = 肘、`1` = 手首）。 |
| **分配カーブ / カーブ指数** | `Linear` / `1.0` | `Linear`（均等）/ `Power`（指数 `p` で手首寄り）/ `SmoothStep` から選択します。 |
| **肘補助ボーンを曲げのみ追従にする** | ON | 肘の補助ボーンの遠位ソースを曲げ専用基準ボーン `N` に切り替え、ひねりを拾わないようにします（推奨）。 |
| **既存ツイストリグがあっても適用** | OFF | 既存の前腕ツイストボーン（Constraint 駆動）にウェイトが乗っているメッシュにも強制適用します（既存ツイストボーンのウェイト自体は変更しません）。 |
| **ノット丸め閾値** | `0.15` | ノット端に近い頂点を単一ボーンへ丸めてウェイトスロットを節約する閾値。 |

### 4.5 ツイストボーン分類・4ボーン制限・診断

- **ツイストボーン自動分類**: 親子関係と Constraint 依存から、既存のツイストボーンや剛体子ボーンを近位（`G_P`）・遠位（`G_D`）へ自動分類します。
- **遠位ソースモード / 上書き**: 補助ボーンが参照する下肢側ソースボーンの決定方式（通常は `AutoLowerBone` のままで問題ありません）。
- **手動追加（近位 `G_P` / 遠位 `G_D`）・手動除外ボーン**: 自動分類で拾えない特殊な補助ボーンの追加や、揺れもの・ギミックボーンの除外を行えます。
- **4ボーン Tier2 吸収閾値 (`0.05`) / Tier3 ノイズ閾値 (`0.03`)**: VRChat の 1 頂点あたり 4 ボーン制限に達した際、重要なボーンを落とさずに補助ボーン用のスロットを安全に確保するための閾値です。
- **ツイストボーン検出・診断**: 対象メッシュの各ボーンが `G_P` / `G_D` にどう分類されているか、前腕ロール軸の実測状態などを一覧確認できます。

## 5. 対象とするモデルの注意点（ボーン構造やウェイトの分布）

JointKeeper を最大限に活かすため、対象アバター・衣装の以下の点にご注意ください。

1. **Humanoid リグ構成が必須**
   - 親階層に有効な **Humanoid Animator** が存在し、`UpperArm` / `LowerArm` / `UpperLeg` / `LowerLeg` が正しく割り当てられている必要があります。
   - **前腕ツイスト分散** を使う場合は、`Hand` ボーンが存在し、アバターの Humanoid 設定で前腕ひねり時に `LowerArm` が実際にロールする構成である必要があります（`LowerArm` がほとんどロールしないアバターでは効果が小さくなり、診断パネルに警告が表示されます）。
2. **関節境界のウェイト分布**
   - 肘・膝のボリューム維持は、**影響範囲（ROI）内で近位（上肢側）と遠位（下肢側）の両方にウェイトを持つ頂点**（既定 `0.01` 以上）に対して適用されます。
   - 関節の境目でウェイトが完全に `100% / 0%` に分かれている硬質パーツ（鎧・メカ部品など）や、肘・膝付近に頂点が存在しないメッシュ（髪・靴など）は自動でスキップされます。
3. **既存ツイストボーンを持つモデル**
   - Constraint で駆動される既存のツイストボーンは自動認識されます。
   - 肘・膝のボリューム維持では既存のねじれ表現を壊さずに共存できます。
   - 前腕ツイスト分散は、すでに既存の前腕ツイストボーンにウェイトが乗っているメッシュでは二重適用を避けるため自動スキップされます（必要に応じて詳細設定の `既存ツイストリグがあっても適用` で上書き可能です）。
4. **手首より先にウェイトがある衣装と前腕ツイスト分散**
   - 手袋・袖口が手の甲まで覆う衣装・素体メッシュで前腕ツイスト分散を使う場合、`ひねり追従率` を `1.0` 未満にすると手首でねじれの段差が生じます（Inspector に警告が表示されます）。`1.0` のまま使用してください。
5. **前腕に PhysBone が付いている衣装**
   - 袖口のリボンやフリルなど、前腕に PhysBone が付いている部位は元のボーンのロールで動き続けるため、前腕ツイスト分散を有効にすると周囲の袖とわずかにずれる場合があります。
6. **Modular Avatar（Merge Armature / Scale Adjuster）との併用**
   - Blender 出力の **100 倍スケール Armature** を持つ衣装や、`MA Scale Adjuster` が付いた衣装にも非破壊ビルド・Edit モードプレビューともに対応しています。
   - ただし **破壊的ベイク（Bake & Replace）** を使用した後に `MA Scale Adjuster` の数値を変更した場合は、`再ベイク (Re-Bake)` を実行してください。

## 6. Q&A（ボーン追加条件・パフォーマンス・仕様）

### Q1. ボーンや Constraint は何本追加されますか？ どんな条件で増えますか？

- **肘・膝のボリューム維持（既定）**
  - 有効な関節（左右の肘・膝）ごとに **1 ボーン ＋ 1 VRC Parent Constraint** が生成されます。
  - **共有（重複排除）仕様:** 同じアバター上で複数の衣装（または素体と衣装）に `JointKeeper` を付けていても、同じ関節の **リグ設定（追従率・90° 押し出し量・ピボット調整・外側方向オフセット・参照ソースボーン）が一致していれば、補助ボーンは 1 本だけ生成されて共有されます**。
  - したがって、標準設定のまま全身の衣装に付けても追加は **最大 4 ボーン / 4 VRC Constraints** です。
  - 同じ関節に対して異なるリグ設定（例：衣装 A は押し出し `0.002`、衣装 B は `0.005`）を指定した場合のみ、設定バリエーションごとに追加ボーンが 1 本増えます。また、対象メッシュに影響頂点が 1 つもない関節ではボーンは生成されません（0 本）。

- **前腕ツイスト分散（オプション・既定 OFF）**
  - 有効な肘 1 箇所につき、**Aim ターゲット 1 本（Constraint なし）＋ 曲げ専用基準ボーン `N` 1 本（`VRCAimConstraint` 1 個）＋ 中間ツイストボーン** が生成されます。
  - 中間ツイストボーンの本数は **`区間数 - 1` 本**（`ひねり追従率 < 1.0` の場合は **`区間数` 本**）で、各中間ボーンに `VRCRotationConstraint` が 1 個付きます。
  - 既定値（`区間数 = 3`、`ひねり追従率 = 1.0`）の場合、片腕あたり **4 ボーン / 3 VRC Constraints**、両腕で **8 ボーン / 6 VRC Constraints** です。
  - こちらも同じ腕の複数メッシュ間で `N` および同じ追従率 `k` を持つ中間ボーンは **自動共有** されます。

### Q2. VRChat のパフォーマンスランクへの影響は大きいですか？

- JointKeeper が生成するのはすべて VRChat ネイティブの **VRC Constraints**（`VRCParentConstraint` / `VRCAimConstraint` / `VRCRotationConstraint`）であり、旧来の Unity Constraint より軽量かつ Quest / Mobile 環境にも対応しています。
- 既定設定（肘・膝のみ、前腕ツイスト分散 OFF）では **最大 +4 ボーン / +4 VRC Constraints** 程度のため、パフォーマンスランクへの影響は極めて小さいです。
- 前腕ツイスト分散を使う場合に Constraint 数をさらに抑えたいときは、詳細設定の **`区間数` を `2`** にすると片腕あたり 3 ボーン / 2 VRC Constraints（両腕で 6 ボーン / 4 VRC Constraints）まで削減できます。

### Q3. 複数の衣装やアバタールートに同時に `JointKeeper` を付けても大丈夫ですか？

はい、問題ありません。同じメッシュ・同じ関節に複数の `JointKeeper` が重なった場合は、以下の優先順位で自動的に 1 つだけが適用され、二重適用は起きません。

1. `ManualList` 指定 ＞ `AutoDetect`
2. 対象メッシュに近い（階層が深い）オブジェクトに付いているコンポーネント ＞ 親（アバタールート側）のコンポーネント

そのため、「アバタールートに全体用の `JointKeeper` を置きつつ、特定の衣装だけ個別に `JointKeeper` を付けて押し出し量を変える」といった運用が可能です。

### Q4. Modular Avatar や Avatar Optimizer (AAO) と併用できますか？

はい。JointKeeper は NDMF の `Transforming` フェーズにおいて **Modular Avatar の後・Avatar Optimizer (AAO) の前** に実行されます。`MA Merge Armature` や `MA Scale Adjuster` で統合・調整された後のボーンに対して処理が行われ、その後の AAO によるメッシュ・ボーン最適化とも問題なく連携します。

### Q5. Edit モード曲げプレビューを使うと元のアバターが壊れたりしませんか？

変更されません。NDMF Preview の一時的な影ボーン階層上で計算しているため、シーン上の元ボーンの回転や元のメッシュアセットは一切書き換わりません。プレビューを OFF にすれば即座に元表示へ戻ります。

### Q6. 付けたのに効果が出ない・ボーンが生成されない場合は？

以下をご確認ください。

1. `JointKeeper` が **Humanoid Animator** を持つアバター配下に配置されているか。
2. 対象メッシュの肘・膝付近に、上肢側と下肢側の両方にウェイトが乗った境界頂点が存在するか（`ヒートマップ表示 → HelperWeight` で確認できます）。
3. すでに **`Bake & Replace` 済み（Baked 状態）** になっていないか（Baked 状態では NDMF ビルドがスキップされます。設定を変えた場合は `再ベイク` を押してください）。
4. `詳細設定 → ツイストボーン検出・診断` および Unity の Console ログに警告やスキップ理由が出ていないか。
